# Strike Elite for Android

Projek Android untuk versi HTML Strike Elite sedia ada. Permainan 1v1 offline dimuatkan daripada aset tempatan dengan skrin penuh landskap.

Ekstrak ZIP ke akar repo GitHub, termasuk folder tersembunyi `.github`. Buka Actions → Build Android APK. Selepas binaan lulus, muat turun artifak Strike-Elite-APK dan ekstrak app-debug.apk.

Binaan tempatan: JDK 17, Gradle 8.9 dan Android SDK 35; jalankan `gradle :app:assembleDebug`.
